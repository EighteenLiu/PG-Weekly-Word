# 平谷区垃圾分类周报生成程序

本项目用于根据区级基础台账、市级检查台账、Jinja DOCX 模板和街乡镇分组配置，生成《平谷区垃圾分类桶站检查情况通报》Word 文档。生成过程中会临时生成问题台账和统计摘要用于校验，完成后自动清理。

## 运行

安装依赖：

```powershell
pip install -r requirements.txt
```

启动桌面程序：

```powershell
python app.py
```

程序启动后会自动在项目目录中查找并填入常用文件：

- `input\周报模板.docx`
- 名称包含“基础台账”的区级基础台账
- 可识别市级工作表的 `.xlsx` 市级台账
- 默认输出目录 `output`

如果自动识别不符合本次生成需要，可以在界面中手动重新选择，或点击“自动查找文件”重新填入空缺项。

界面中依次选择：

- 区级基础台账 `.xls`
- 周市级检查台账 `.xlsx`
- Jinja 周报模板 `.docx`
- 分组清单 `.xlsx` 可选上传
- 输出目录、报告年份、区级周期、市级周期、市级工作表和上周区级问题总数

分组默认读取 `docs\平谷区街乡镇分组清单.json`。这个 JSON 可以直接编辑，保存后下次生成立即生效。界面中的分组清单为可选上传；如果上传的 Excel 分组与 JSON 不一致，程序会自动把 Excel 内容同步写回 JSON。界面提供“新增点位”按钮，可手动填写城乡镇和分组并写入后台 JSON；如果当前仍选择上传分组清单，生成时仍优先使用上传文件。

“下一步重点工作”的主要措施句从 `docs\周报生成逻辑汇总.md` 中的“主要措施句匹配口径”表读取，不再写死在代码中。需要调整具体问题对应的措施表述时，直接维护该表的“工作方向、匹配项、主要措施句”即可；`docs\平谷区指标管理指标清单.md` 和 `docs\平谷区指标管理指标清单.json` 是从指标管理 HTML 整理出的指标清单，可用于核对匹配项覆盖范围。若逻辑文档缺失、读取失败，或某个工作方向缺少默认句，程序仍会生成周报，并在生成完成提示和统计摘要中写入配置提示，同时对缺失项使用通用兜底句。

周期可以留空，程序会自动识别：区级和市级周期均优先从台账文件名提取；文件名无法提取时，区级根据案件日期、市级根据当前所选工作表的 `日期` 列取最早和最晚日期。需要手动修正时，使用 `07.04-07.10` 或 `7月4日-7月10日` 这类格式。生成到正文时会显示为 `07月04日-07月10日`。区级周期用于筛选区级记录；市级数据先由所选工作表确定，再按市级周期筛选该表的 `日期` 列。所选市级工作表在周期内没有匹配记录时，程序会提示重新选择工作表或修正周期。

市级工作表需要先选择“周市级检查台账”，程序会自动解析工作表列表；也可以点击“解析工作表”重新读取，再从下拉框选择本周对应工作表。切换工作表后，市级周期会跟随所选工作表重新识别。

上周区级问题总数为必填项，用于生成“较上周减少/增加、降幅/增幅”的对比句。

点击“校验并预览”可查看文件校验状态、识别周期、问题总数、检查点位数、市级六大类预览和区级排名表预览。点击“生成周报”后，输出目录会生成：

- `2026年平谷区垃圾分类桶站检查情况通报（周期）.docx`

生成过程中内部产生的 `问题台账（周期）.xlsx` 和 `生成统计摘要（周期）.json` 会写入项目内 `work\tmp` 的单次临时目录，周报生成结束后自动清理，不保留在输出目录。

生成后的周报会对重点展示内容做格式处理：总体情况图表的平均值折线按全区整体问题率显示 `仿宋_GB2312` 10 号加粗的平均数标签（总问题数 / 总检查小区、村数，不乘 100），纵轴最大值自动收口到高于最高值的下一个 5 倍数，刻度间隔固定为 5；市级六大类分析中“问题突出的乡镇是”后的乡镇数量加粗；区级问题率排名表每个组别的第一行加粗。

## 命令行生成

也可以使用命令行生成，便于复核样例：

```powershell
python -m pg_weekly_word.cli `
  --district "data\周报\7月4日-7月10日基础台账.xls" `
  --city "data\周报\7.2---7.5(1).xlsx" `
  --template "input\周报模板.docx" `
  --output "output" `
  --year 2026 `
  --district-period "07.04-07.10" `
  --city-period "07.02-07.05" `
  --sheet "Sheet4" `
  --previous-district-issues 569
```

## 约束

- 程序只读取用户选择的模板和原始台账，不修改模板文件和原始台账。
- 生成过程的临时目录固定在项目内 `work\tmp`，不主动写入 C 盘临时目录。
- 默认不打包、不压缩。

## 打包

需要生成桌面端发布目录时，在项目根目录执行：

```powershell
python build_release.py
```

脚本使用 PyInstaller 生成 `release\平谷周报生成工具\平谷周报生成工具.exe`，并复制 `docs`、`input`、`README.md` 到发布目录。打包临时目录固定在项目内 `work\build`，默认不生成压缩包。
