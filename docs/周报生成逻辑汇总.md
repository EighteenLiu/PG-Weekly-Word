# 周报生成逻辑汇总

## 周期识别与显示规则

### 区级周期自动识别

区级周期按以下优先级识别：

1. 优先从区级基础台账文件名中提取起止月日。
2. 文件名中无法提取周期时，根据台账有效记录的案件日期，取最早日期和最晚日期作为区级周期。
3. 每条记录的案件日期依次从 `检查时间`、`检查日期`、`具体问题_11` 中读取；以上字段均无法识别时，使用 `上报时间`。
4. 使用 `上报时间` 推算案件日期时，时间在当天 12:00 及以后，该记录的案件日期按次日计算。

例如文件名 `7月4日-7月10日基础台账.xls` 可直接识别为 `07.04-07.10`。

生成周报时，区级周期会用于筛选区级基础台账记录：案件日期处于周期起止日期范围内的记录参与统计；无法取得案件日期的记录保留并参与统计。

### 市级周期自动识别

市级周期按以下优先级识别：

1. 优先从市级台账文件名中提取起止月日。
2. 文件名中无法提取周期时，根据当前所选工作表的 `日期` 列，取最早日期和最晚日期作为市级周期。
3. 未手动指定市级工作表时，程序选择最后一个包含两行以上有效内容的工作表；界面切换工作表后，会根据新工作表重新识别市级周期。

例如文件名 `7.2---7.5(1).xlsx` 可直接识别为 `07.02-07.05`。

市级数据先限定为当前所选工作表，再按照市级周期筛选该工作表的 `日期` 列。只有日期处于周期起止范围内的记录参与乡镇数、检查点位数、问题总数、六大类问题和下一步重点工作统计；日期为空、无法识别或不在周期内的记录均不参与统计。

如果当前所选工作表在市级周期内没有任何匹配记录，程序停止生成并提示该工作表的实际日期范围，要求重新选择市级工作表或修正市级周期，避免整张错误子表被计入周报。

### 支持的周期和日期格式

手动填写区级周期或市级周期时，建议使用以下任一格式：

- `07.04-07.10`
- `7.4-7.10`
- `07/04-07/10`
- `7月4日-7月10日`

程序会统一转换为 `07.04-07.10` 格式。无法自动识别周期时，需要在界面中手动填写。

台账日期单元格优先使用 Excel 日期格式，同时支持以下内容：

- `2026-07-04`
- `2026/07/04`
- `2026.07.04`
- `2026年7月4日`
- `20260704`
- `2026-07-04 10:30:00`
- Excel 日期序号

文件名周期的优先级高于台账日期列。只要文件名中能够提取出两组月日，程序就采用文件名周期；若文件名周期与台账实际日期不一致，应修改文件名或在界面中手动修正周期。

### 周期显示

- 总标题和一级标题中的周期保留短格式，例如 `07.04-07.10`。
- 正文叙述中的周期使用中文日期格式，例如 `07月04日-07月10日`。

### 输出文件命名

- 周报 Word 文件名使用报告年份和区级周期短格式：`2026年平谷区垃圾分类桶站检查情况通报（06.20-06.26）.docx`。
- 报告年份来自界面或命令行填写的“报告年份”，区级周期随识别或手动填写的区级周期动态变化。
- 问题台账和统计摘要仍使用区级周期短格式命名，但只写入项目内 `work\tmp` 的单次临时目录，用于行数校验、问题排查和内部记录；周报生成结束后自动清理，不保留在正式输出目录。

## 上周对比句

区级总体情况段落中，区级问题总数表述为：

`共发现{{ district_total_issues }}处桶站垃圾分类问题。较上周{{ previous_district_issues }}处减少{{ diff }}处，降幅{{ percent }}%。`

当本周问题数高于上周时，改为“增加、增幅”；持平时写“较上周{{ previous_district_issues }}处持平。”

## 总体情况图表

“一、总体情况”部分的图表数据来源应与“平谷区垃圾分类现场检查问题率排名表”一致。

图表更新口径：

- 乡镇街道：取排名表中的 `town`。
- 问题数：取排名表中的 `issue_count`。
- 检查小区、村：取排名表中的 `checked_count`。
- 问题率：取排名表中的 `issue_rate`。
- 展示顺序：与排名表一致，即按城区组、平原组、山区组展示，每组内部按问题率从高到低展示。
- 柱形颜色继承周报模板中的分组配色，并根据实际排名行所属组动态应用，组内行数变化时颜色仍保持一致。

## 区级问题归并规则

- 原始问题台账中的 `2级指标` 保持不变。
- 周报区级突出问题、各组主要问题、重点乡镇主要问题及下一步工作判断中，将“容器满冒”和“容器整洁率”合并统计为“容器满冒脏污”。
- 合并后的数量为两类原始问题数量之和，占比仍以区级问题总数为分母计算。

## 区级重点乡镇段落规则

- 每组取问题率最高的乡镇。
- 平原组若同时为全区最高，写“位列本周检查乡镇问题率首位”。
- 主要问题取该乡镇问题数前三到四类。
- “容器完好率”不进入重点乡镇主要问题；“容器整洁率”与“容器满冒”合并为“容器满冒脏污”后参与统计。

## 下一步重点工作生成规则

“四、下一步重点工作”采用“固定方向标题 + 具体问题措施句动态组合”，不再按问题大类套用整段固定正文。措施句库优先沿用已有周报中对应问题的原话；已有周报缺少对应问题表述时，才使用补写的兜底措施句。

- 市级六大类按问题数降序选择最多四个工作方向，问题数为 0 的类别不进入候选。
- 每个工作方向的标题固定，正文从该方向的具体小问题措施句库中选择。
- 具体小问题按本周问题数降序处理，正文最多组合 3 条不重复措施句。
- 多个具体问题命中同一措施句时只写一次。
- 该方向只有 1 种实际问题时只写 1 条措施句，不补通用句凑数。
- 市级具体问题不足时，可结合区级重点问题补充同方向措施句。
